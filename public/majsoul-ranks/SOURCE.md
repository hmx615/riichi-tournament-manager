# Mahjong Soul rank badges

The PNG files in this directory are the official Simplified Chinese four-player rank badges extracted from Mahjong Soul game resources.

Source archive: <https://files.riichi.moe/mjg/game%20resources%20and%20tools/Mahjong%20Soul/game%20files/ranks/>

Source filenames: `Novice [chs].png`, `Intermediate [chs].png`, `Expert [chs].png`, `Master [chs].png`, `Saint [chs].png`, and `Celestial [chs].png`.
